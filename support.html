Common issues

The CSV does not import correctly

Make sure you are using Blooket's spreadsheet import workflow and that the generated file has not been manually reformatted in a way that changes its column structure.

The questions do not match my lesson

Upload the lesson, worksheet, notes, or unit package you want used as the source. Blooket Generation is intended to base questions on the materials you provide.

I need a different number of questions

State the number directly in your prompt, such as “Create 40 questions from this unit.”
